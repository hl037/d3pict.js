# API reference

Generated from the source and its comments, one page per class, interface, function and type. The guide tells how to use the library; this reference tells what each piece takes and gives.

- [**d3pict**](/api/d3pict/): the core. Chart, axes, series, renderers, tools, the cursor, the tooltip, the legend, the layout.
- [**d3pict/vue**](/api/d3pict/vue/): the Vue plugin and components.
- [**d3pict/react**](/api/d3pict/react/): the React provider and components.

New to the library? Start with [the guide](/guide/getting-started) and [the concepts](/guide/concepts).
