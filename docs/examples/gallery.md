# Chart types

Every chart type of the library has its own page: the chart, live, and the code that creates it for Core, Vue or React, complete and ready to copy. Each is a few objects on a chart (axes, a renderer, sometimes a transform or an annotation); the [reference](/guide/chart-types) says how each one is built, and the [showcase](/examples/showcase) combines them on a few charts.
