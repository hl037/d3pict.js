# Types de graphiques

Chaque type de graphique de la bibliothèque a sa page : le graphique, en direct, et le code qui le crée pour Core, Vue ou React, complet et prêt à copier. Chacun n'est que quelques objets sur un graphique (axes, un rendu, parfois une transformation ou une annotation) ; la [référence](/fr/guide/chart-types) dit comment chacun est construit, et la [vitrine](/fr/examples/showcase) les combine sur quelques graphiques.
