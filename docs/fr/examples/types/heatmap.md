# Carte de chaleur

Deux catégories et une valeur : `D3PHeatmapRenderer` colore chaque cellule avec un `D3PColorScale`, et `D3PColorLegend` montre l'échelle. Le domaine automatique ajuste les couleurs aux valeurs.
