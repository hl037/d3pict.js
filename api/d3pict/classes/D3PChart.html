Class: D3PChart ​

Defined in: core/chart.ts:132

A chart: an svg in a container, with the margins around its plot, a layout for titles and legends, and the services that objects use (the axes, the renderers, the coordinate systems, the interaction area).

Nothing is drawn until objects are attached to it: axes, renderers, tools, a cursor, a tooltip.

Data URL of a PNG rendering of the chart (options.scale pixels for each pixel of the chart, 2 by default). A browser that does not let HTML content (titles, legends) into an image, Safari for one, draws the chart without it, and says so in the console: exportSVG keeps it.

exportSVG() ​

ts
exportSVG(options?): Promise<string>;

Defined in: core/chart.ts:360

The chart as the text of an SVG file, with what shows on a still chart: the pointer's cursor, markers and tooltip are left out, and so is the area that takes the pointer. The file does not depend on the page: it has a background (white unless you say otherwise), a color for the text that follows the color of the page, and the web fonts the chart uses (see D3PExportOptions). The titles and legends, which are HTML, are part of it.
